# Python版CLIとの互換性

比較元はこのブランチの`nijitrack.py`です。全OSで`nijitrack`を生成・インストールし、
従来の`nijitrack-cpp`も同じプログラムの別名として残します。

| Python版の機能 | native版 |
|---|---|
| `-h` / `--help` | 対応。`--name=value`と一意の長いオプションの省略形も対応 |
| `--list-devices` | 全OSでSDL3を使用。0始まりの整数IDと名前をJSON出力 |
| `--device N` | 全OSでSDL3の列挙順の整数IDで取得する。複数カメラでは一覧を再確認 |
| `--osc-host` / `--osc-port` | カメラ利用時は`127.0.0.1:39540`が既定 |
| `--flip` | 推論前に画像を左右反転。姿勢・視線・OSCにも反映 |
| `--show` | 全OS共通のSDL3による常時プレビュー |
| `--show-video` | プレビューの背景映像。無指定時は黒背景 |
| `--show-wire` | MediaPipe公式の接続定義と478ランドマーク |
| `--show-text` | 角度・鼻位置・両眼の視線 |
| `--show-blend` | カテゴリ名・値・棒グラフ |
| `v/w/t/b` | プレビュー各要素の実行中切替 |
| ウィンドウを閉じる | 処理を終了 |
| グローバルキー押下・解放 | カメラ利用時は既定で有効。既存のOS別バックエンドを使用 |

`--show-*`だけではウィンドウを開きません。Python版同様に`--show`も指定します。
カメラ使用時のJSONL標準出力は既定で無効です。

追加の画像処理は`--image`、JSONLは`--json`/`--output`、
既定の送信・キー取得の無効化は`--no-osc`/`--no-keyboard`を使います。
画像モードのOSCとキーボードは従来の試作同様に明示指定で有効です。

モデルは自動取得せず、実行ファイルの隣と親、作業ディレクトリとその親から探します。
配布時は実行ファイルの隣に置くか`--model FILE`を明示してください。
表示バックエンドはSDL3に委ねます。Wayland単独のグローバルキー取得は既存バックエンド同様に未対応です。
キーボードを無効にしてビルドした場合はカメラ起動に`--no-keyboard`が必要です。
macOSのカメラ/入力監視権限はOS側で許可します。

今回の検証はWindowsでのReleaseビルド、引数・既定値・反転・合成フレーム描画・表示切替・終了、
SDL3列挙、インストール後の起動です。Linux/macOSも実装済みですが今回の環境ではビルド・実機検証していません。
FFmpeg除去後の実カメラは30フレームの取得・推論・自動終了を確認しました（その入力では顔検出0件）。公式テスト画像で顔478点・表情52項目・変換行列と両手21点・世界座標・左右判定を各3フレーム検証しました。実キー取得は今回未検証です。

互換性はCLIと既定動作についてのものです。推論のフレーム処理、細かな文字描画、
デバイス一覧の空白や順序（全OS）、エラー文言の完全一致は保証しません。

映像取得と表示は共通SDL3 APIを使います。動画ファイル入力`--video`は廃止し、FFmpeg依存を取り除きました。カメラ映像表示の`--show-video`は維持します。
カメラ番号の順序・文字の外見・描画結果の完全一致は保証しません。SDL3の文字表示はASCIIのデバッグ用フォントです。

取得、推論・OSC送信、表示は標準C++のスレッドと同期機構で分離しています。
カメラとプレビューは最新1フレームを保持します。
SDL3のイベント処理と描画はメインスレッドで動作し、停止時は停止要求を伝えてjoinします。
